N NLSI TELEMETRY AGENT RELEASE NOTES
WINDOWS · ETS2 & ATS

Install the update

Install the complete plugin package so the DLL and its accompanying files stay together. Do not copy or install the DLL by itself.

  1. 01

    Close the game

    Exit Euro Truck Simulator 2 or American Truck Simulator before replacing plugin files.

  2. 02

    Open the game’s plugin folder

    In Steam, open the game’s Manage menu and choose Browse local files. Open the 64-bit game folder, then its plugins folder. Create plugins if it is not there.

  3. 03

    Copy the complete package

    Copy all files from the supplied plugin package into the game’s plugins folder. Keep the package’s folder structure and supporting files intact. When updating, replace the previous NLSI plugin files.

  4. 04

    Launch and verify

    Start the game and the NLSI Telemetry Agent. Confirm the agent reports a connection.

i

Updating an existing install? Keep a backup of the current NLSI plugin files until the new version connects successfully.

A clearer view of your session

The console now presents telemetry as a live dashboard instead of repeatedly printing complete packets.

  • ✓Press D to inspect the latest telemetry packet as formatted JSON.

  • ✓Press Q to exit the agent cleanly.
