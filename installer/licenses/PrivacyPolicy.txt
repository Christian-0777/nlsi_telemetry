NLSI EXCLUSIVE LOGBOOK v1.4.3-BETA
PRIVACY POLICY

1. INFORMATION PROCESSED BY THE APPLICATION

The native Application receives supported ETS2/ATS telemetry from the local
SCS plugin over the computer's local interface. Values may include game,
vehicle, navigation, job, session, and provider status fields when the game
and plugin supply them. TruckSim GPS telemetry is read locally from the
Windows shared-memory mapping created by the game plugin. Telemetry is processed
locally to display current application state. Provider events, session
lifecycle records, completed/cancelled job events, TXT and NLSI logs, complete
revision-13 shared-memory sample bytes, decoded raw fields, normalized values,
and pending synchronization record IDs are stored under the current user's
Windows application data directory. Telemetry file rotation creates additional
files; it does not delete historical data.

The current native Application does not send gameplay telemetry to Nabski
Logistics and Solutions Inc. or another remote telemetry service. It does not
require an online account.
Unavailable telemetry values are not intentionally filled with invented
values. The updater may contact GitHub to check for releases. The Active Mods
page reads the ETS2 and ATS game.log.txt files from the current user's
Documents directory. When a Workshop mod is active, the page may request that
item's public Steam Workshop page and a preview image from an HTTPS Steam image
host. Steam may receive the Workshop item ID, IP address, and standard request
metadata. No game telemetry is included in those requests; thumbnails are
optional and may be unavailable while offline.

2. INSTALLATION AND LEGACY CLEANUP

The installer places Application files in the selected installation
directory. During an update, application files are replaced in place and
existing per-user application data is retained. Setup automatically installs
the bundled official TruckSim GPS plugin only into detected ETS2/ATS Steam
plugin folders; a different existing plugin DLL is not overwritten. The uninstaller
removes only a recorded TruckSim GPS plugin whose contents still match the
installed copy.
Setup removes the legacy
C:\nlsi-tem application directory only when it does not contain the known
user-data folders (config, data, logs, or app\test\output). If any of those
folders are present, setup leaves the legacy directory untouched to protect
that data. The uninstaller does not target user data stored outside the
Application installation directory, except for managed TruckSim GPS plugin
copies described above, shortcuts, and the optional Windows startup shortcut
you choose.

3. OPTIONAL EXTERNAL LINKS

The Application's About page provides links to the Nabski Logistics and
Solutions Inc. community, CEO and
developer TikTok accounts, and the TruckSim GPS project. If you open one,
the corresponding third-party website may receive information such as your
IP address and browser data under its own privacy policy. Setup does not open
these links automatically. Workshop item source links on Active Mods open
Steam only when selected; optional previews may load while viewing that page.

4. RETENTION AND CONTROL

Telemetry displayed by the native Application is handled locally. You
control whether to install or uninstall the Application and whether to open
the optional links. The Windows uninstaller removes installed Application
files; it does not recreate C:\nlsi-tem.
